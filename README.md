# 👟 RunAnalyz Mk2 (Pivot Project)

> **"지저분한 기능은 덜어내고, 러너가 매일 열어보고 싶은 본질에만 집중한다."**

---

## 🎯 1. 피봇 배경 및 문제의식 (Why Pivot?)
- **기존 RunAnalyz의 한계**:
  - 러닝화 위키(ShoeF), 스트라바/가민 연동, 수많은 계산기 및 복잡한 시각화가 한 화면에 뒤섞여 복잡도와 유지보수 비용 급증 (`app.js` 260KB+, `style.css` 200KB+).
  - 유저 관점에서 "내가 지금 이 사이트에서 무엇을 얻어야 하는가?"가 직관적으로 와닿지 않음.
- **Mk2의 핵심 지향점**:
  - **오버엔지니어링 제로**: 불필요한 위젯 제거, 단일 핵심 가치(Killer Value) 중심.
  - **클린 라이트 테마 (Toss/Apple 감성)**: 무거운 다크 테마에서 벗어나 모바일 친화적인 `#F8FAFC` 라이트 UI.
  - **0초 체감 속도 & 무과금 정적 배포**: 순수 HTML/JS/CSS 기반, 즉각적인 로컬/브라우저 연동.

## 💡 2. YC 렌즈로 본 3대 핵심 질문 (GStack Office Hours)
1. **누가 왜 쓰는가? (Target Persona)**:
   - 마라톤 풀/하프를 준비하거나 꾸준히 달리는 러너.
   - 가민 커넥트나 스트라바의 방대한 데이터 대신, **"오늘 내 페이스/심박이 목표 대비 어땠는지", "다음 훈련 강도는 어떻게 설정해야 하는지"**를 3초 안에 보고 싶은 러너.
2. **10배 뛰어난 킬러 한 방 (10x Value)**:
   - 복잡한 대시보드가 아닌 **"단 1개의 러닝 핏 지수 (Running Economy / EF) & 훈련 강도 처방기"**.
3. **가장 작은 MVP 스코프 (3-Day Scope)**:
   - GPX / FIT 파일 또는 스트라바 최근 기록 업로드/조회 → 즉시 심박 대비 효율(EF, Pw:Hr) 및 권장 페이스 진단 카드 노출.
